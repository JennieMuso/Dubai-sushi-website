# JIN restaurant website concept

An editorial multi-page website concept for an intimate sushi restaurant in Downtown Dubai.

## Project structure

```text
.
├── assets/                 # Optimized WebP imagery and favicon
├── index.html              # Homepage
├── experience.html         # Dining experience
├── chef.html               # Chef biography
├── omakase.html            # Omakase experience
├── menu.html               # À la carte menu
├── private-dining.html     # Private dining
├── reservations.html       # Reservation enquiry
├── styles.css              # Homepage styles
├── inner.css               # Inner-page styles
├── script.js               # Homepage interactions
├── inner.js                # Shared inner-page interactions
├── robots.txt
├── sitemap.xml
└── site.webmanifest
```

Open `index.html` in a browser to begin. The project includes:

- `experience.html`
- `chef.html`
- `omakase.html`
- `menu.html`
- `private-dining.html`
- `reservations.html`

The pages are responsive and include local WebP concept imagery, full-width image heroes, an accessible full-screen mobile navigation, selective parallax, scroll-triggered motion, reduced-motion support, and an illustrative reservation enquiry form. Below-fold imagery uses native lazy loading and async decoding.

The project also includes a favicon, web app manifest, robots.txt, sitemap.xml, Open Graph and Twitter metadata, a WebP social sharing image, canonical URLs, and structured data for the restaurant and menu.

The JIN name, chef biography, and all interior and food imagery are concept material. Dish descriptions and AED prices are illustrative. Confirm Jin Xiwei's career details, the final venue, menu, pricing, and booking route before a public launch. The page does not accept reservations.
